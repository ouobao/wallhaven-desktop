# Wallhaven Studio

Wallhaven 的 Windows 桌面客户端，使用官方 Wallhaven API 提供实时浏览和下载能力。

## 已实现功能

- 发现、最新上传、热门榜单、随机探索
- 关键词、标签、`@用户名` 搜索
- 分类、纯净度、榜单时间、排序方向、最低/精确分辨率、画面比例、主色调筛选
- 壁纸详情、标签搜索、相似壁纸、上传者与文件信息
- 原图下载、选择下载目录、设置为 Windows 桌面壁纸
- 本地收藏，保存完整壁纸信息，重启后仍可使用
- Wallhaven API Key 连接、官方浏览偏好同步、私有/公开 collections 浏览
- `Ctrl + K` 聚焦搜索框、网格/列表视图、侧栏折叠、高对比度主题
- 无网络或未配置 API 时提供演示预览，并明确显示当前连接状态
- 应用内检查更新：查询 GitHub Releases，手动下载，下载完成后一键重启安装

### 自动换壁纸与托盘

- 按 15 分钟 ~ 24 小时的间隔自动更换桌面壁纸，来源可选热门榜单、随机探索、本地收藏、下载目录
- 定时切换只在系统空闲超过 90 秒后执行，不会打断全屏视频或游戏
- 可选同时设置锁屏；锁屏失败不影响桌面壁纸
- 关闭窗口默认最小化到系统托盘，托盘菜单可立即换一张、开关轮换、打开下载目录、退出
- 托盘常驻期间轮换照常运行，不需要窗口开着

### 桌面壁纸显示方式

支持填充、适应、拉伸、居中、平铺、跨屏铺满六种方式。切换后会立即重绘当前桌面，不会沿用系统上一次的平铺设置。

### 键盘操作

| 快捷键 | 作用 |
| --- | --- |
| `Ctrl + K` | 聚焦搜索框 |
| `Ctrl + F` | 打开筛选器 |
| `Ctrl + D` | 打开下载管理 |
| `Ctrl + R` | 刷新当前内容 |
| `Ctrl + A` | 全选当前页壁纸 |
| `Esc` | 逐层关闭弹窗 / 退出多选 |
| `←` `→` | 详情里切换上一张 / 下一张 |
| `空格` | 详情里收藏 / 取消收藏 |
| `D` | 详情里下载原图 |
| `W` | 详情里设为桌面壁纸 |
| `?` | 打开快捷键面板 |

### 其他

- 批量选择：多选后批量下载、批量收藏；`Ctrl + A` 全选当前页
- 右键菜单：查看详情、下载、设为桌面/锁屏、查找相似、复制 ID、复制官网链接
- 下载预览支持滚轮缩放、拖动平移、双击切换 100%
- 下载队列限制 3 并发，其余任务排队，避免触发 Wallhaven 限流
- API 请求带 15 秒超时、429/5xx 指数退避重试，断网时不会一直停在“正在同步”
- 收藏保存在数据目录的 `favorites.json`，支持在设置里导出 / 导入 JSON
- 单实例运行，重复启动会唤起已有窗口；窗口大小与位置会被记住
- 渲染异常时显示可恢复的错误页，不再白屏

## 账号连接

Wallhaven 官方 API 使用 API Key，而不是把站内密码交给第三方客户端。打开应用里的“账户连接”，从 Wallhaven 的 `Account Settings` 生成 API Key 并粘贴即可。

API Key 会通过 Electron 的系统安全存储保存。应用不保存站内密码；NSFW 内容和私有 collections 需要有效 API Key。

## 开发

```bash
pnpm install
pnpm run dev
```

## 构建 Windows 安装程序

```bash
pnpm run dist
```

安装器会输出到 `release/Wallhaven-Studio-Setup-1.0.0.exe`，安装向导默认创建桌面快捷方式。

## 应用更新

应用内置 `electron-updater`，更新源是 GitHub Releases（`package.json` 里的 `build.publish`）。左侧栏「检查更新」会查询最新版本：有新版可手动下载，下载完成后点「重启并安装」静默升级并自动重启。

发布新版本的步骤：

1. 修改 `package.json` 的 `version`（如 `1.0.1`）
2. 执行 `pnpm run release`，构建产物会自动上传到 GitHub Releases
3. 旧版本客户端下次检查更新时即可看到新版本

首次使用需要先登录 GitHub CLI（`gh auth login`）或设置 `GH_TOKEN` 环境变量。若只构建不发布，继续用 `pnpm run dist`。

更新过程日志写在数据目录的 `updater.log`，排查问题时可直接查看。

## API 说明

Wallhaven 官方公开 API 不提供完整的站内登录会话、收藏写入和上传接口，因此客户端将收藏作为本地收藏保存；个人 collections、账户浏览设置和受限内容使用官方 API Key 读取。
